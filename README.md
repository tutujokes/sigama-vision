## 🌟 Sobre o Projeto

Olá! Este é o **SIGAMA Vision**, um MVP (Produto Mínimo Viável) que desenvolvi para o processo seletivo do **Edital Nº 01/2025 AGED/FAPEMA** - Projeto Tecnologia e Inovação em Gestão Agropecuária (PTG).

## 🎯 O Problema Que Estamos Resolvendo

A **AGED (Agência Estadual de Defesa Agropecuária do Maranhão)** processa milhares de GTAs (Guias de Trânsito Animal) mensalmente de forma manual. Isso resulta em:

- ⏰ Tempo significativo para processar cada documento manualmente
- 📄 Risco de fraudes e erros humanos
- 🗂️ Falta de dashboards analíticos e insights em tempo real
- 🔍 Dificuldade em detectar anomalias e padrões suspeitos

---

## 💡 Nossa Solução

O SIGAMA Vision é uma plataforma web moderna que oferece:

### ✨ **Para Gestores/Coordenadores**
- 📊 Dashboard estadual completo com KPIs em tempo real
- 🗺️ Mapa de calor das 18 unidades regionais do Maranhão
- 🔍 Detecção automática de anomalias e fraudes
- 📈 Análises preditivas e relatórios consolidados

### 🛡️ **Para Fiscais/Servidores AGED**
- 📱 Monitoramento regional mobile-first
- 🤖 **Vaqueiro Digital**: IA que analisa documentos em pouquíssimos segundos
- 📋 Registro de fiscalizações em campo com checklist digital
- ⚠️ Alertas de anomalias da sua região

### 🐄 **Para Produtores Rurais**
- 🎫 Emissão simplificada de e-GTAs
- 📊 Gestão completa do rebanho
- 💉 Calendário inteligente de vacinação
- 📜 Certificados sanitários digitalizados

---

## 🤖 Vaqueiro Digital - O Diferencial

A estrela do projeto é o **Vaqueiro Digital**, um assistente de IA, que:

1. 📸 Recebe foto ou upload de documento (GTA, certificado, nota fiscal)
2. 🧠 Extrai dados automaticamente com OCR + validação semântica
3. ✅ Gera score de conformidade (0-100%)
4. 🚨 Identifica inconsistências e possíveis fraudes
5. ⚡ **Reduz minutos de trabalho manual para poucos segundos**

## 🛠️ Stack Tecnológica

Construído com amor usando:

- ⚛️ **React 18** + TypeScript
- 🎨 **Tailwind CSS** + shadcn/ui (design system)
- 📊 **Recharts** (visualização de dados)
- 🤖 **Claude API** (Anthropic) - IA para análise de documentos
- 🗺️ **React Router** (navegação SPA)
- 🚀 **Vite** (build tool ultrarrápido)
- 📦 **Vercel** (deploy)
